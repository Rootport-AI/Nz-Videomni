## 用語（初出の略語の説明）

- **reserved**: PyTorch が GPU から予約したメモリの山（`peak_vram_reserved_mb`）。**peak**（allocated の山）は、そのうち実際に使っていた量の山（`peak_vram_mb`）。
- **inactive_split**: 予約したが返せない断片の山（`vram16.inactive_split_peak_mib`）。
- **retries**: 割り当て器が確保に失敗してキャッシュを掃除してからやり直した回数（`vram16.num_alloc_retries`）。
- **cap**: VRAM 16GB mode がノイズ除去（denoise）の頭で掛ける割り当て上限（`vram16.cap_mib`。その時点の予約＋空き − 余白 1,024MiB。計画 §1）。
- **S**: DiT（映像を作る本体のネットワーク）に入る行の総数（`sequence.total`＝text＋cond＋audio＋video）。
- **映像＋条件行**: `sequence.video + sequence.cond`（線の軸。計画 §2.2）。**text 行**はプロンプトとキーフレームを符号化した行、**cond** はキーフレームの条件行、**audio** は音声の行。
- **Δ（デルタ）**: その窓の WDDM（Windows の GPU メモリ管理）の共有メモリの中央値 − 基準点の同じ窓の中央値（MB）。+300MB 以上で「退避」。**n** は標本数（約 1 秒に 1 標本）。
- **窓**: server.log の行で区切った区間。`encode`（文章・画像の符号化。記録だけ）・`denoise`（ノイズ除去）・`decode`（VAE の復号）。
- **commit_log**: 監督の `commit_monitor.ps1` が 3 秒ごとに書いたシステム全体のコミット量（`commit_log.csv`）。点ごとの山は `drive2_*.log` の `done … peak=` の行（`commit_table.md`）。
- **c**: 快適の上端（2 回快適）。**U**: c の 1 段上（非快適）。
- **K**: キーフレームの枚数。
- **OOM**: GPU のメモリ不足（out of memory）。
