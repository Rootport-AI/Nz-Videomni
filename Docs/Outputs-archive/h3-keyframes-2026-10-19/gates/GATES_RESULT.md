## 結論

- **合否のある門はすべて合格です。**
  - 1-G2: 2 通り（先頭＋末尾・末尾だけ）とも、A・B（画像の入力と画像読み取り部の出力・DeepStack）・C（配線の差 0）・E が一致しました。
  - 1-G3: T2V の指紋 `0da6111c…` と、先頭だけの I2V の指紋 `77e29687…` が、全桁一致しました。
- GPU 付きの pytest は 176 件合格・飛ばし 0 件・失敗 0 件でした。
- 記録だけの項目も、全部最後まで動きました。
  - VRAM 16GB mode を入れた先頭だけの I2V も、指紋が `77e29687…` で、入れないときと全桁同じでした。
  - API 経由の T2V は 2 本とも `0da6111c…` でした。
- 10 枚のキーフレームでも、ノイズ除去の VRAM の山は 3,859MB（予約 3,896MB）でした。2 枚のとき（3,858MB）とほぼ同じです。生成全体の山は、どの条件でも VAE の復号の 5,065MB です。
