# MiniMax H3 の pi-H3 を製品に入れる段 1 の、実機の確認（2026-11-23）の出典

pi-H3（低ステップの蒸留の差分と、動画VAE の復号器を使わずに画素を出す DWD の組み合わせ）を製品のコードに入れた段 1（単発の生成）の、実機の確認の台本と記録の写しを置く保管庫です。確認の条件・数値・結論の正本は記録簿 `Docs/VERIFICATION_LOG.md` §224、設計の正本は設計正本 `Docs/MINIMAX_H3_DESIGN.md` の裁定 107 と §6.7 にあり、ここには書きません。

**これは 2026-11-23 の時点の写しです。** 最初に写したあと、照合のモジュールを移したあとの回し直し（F1d・P1d・P3d）を終えた時点で、台本・一覧・GPU を使わない確認の記録を写し直し、足された項目の記録を足しました。 元のフォルダは git の追跡外の `outputs/h3-pih3-gates-2026-11-23/` で、正本は常にそちらです。回すときは元のフォルダの台本を使ってください（使い方は `h3_pih3_gates.py` の冒頭の説明にあります。GPU を使う項目は、その都度オーナーの了承を得てから回します）。

## 台本（中身を変えずに写したもの）

- `h3_pih3_gates.py` — 確認の本体。アプリ側の仮想環境で動き、torch を読み込みません。項目ごとに一時の設定と専用のポートでバックエンドを起動して止め、各項目の前に、オーナーのサーバー・エンジンのワーカー・GPU の使用量を確かめます。GPU を使わない確認（`--dry-run`）・GPU の確かめだけ（`--gate-check`）・項目を選んで回す（`--live --only`）・記録から比較と一覧を作り直す（`--post-only`）の使い方があります。
- `engine_direct.py` — 実験（記録簿 §223.12）の対照の項目を、同じ設定でエンジンを直接呼んで回し直す部分（項目 M1）。エンジンの仮想環境で、`h3_pih3_gates.py` から起動されます。
- `make_sheets.py` — 出力の動画から 5 コマを抜いて横に並べた画像を作る部分（オーナーの目視用）。
- `first_frames.py` — 出力の動画の先頭の 8 コマを並べた画像と、隣のコマとの差の数値（`first_frames.json`）を作る部分。

## 記録の写し

- `summary.md`・`summary.json` — 全項目の判定と主な数値の一覧。`summary.json` の `invocations` に、回した順と、そのときの git の状態があります。
- `first_frames.json` — 先頭の 8 コマの、隣のコマとの差（0〜255 の画素の値の差の平均と PSNR）。記録簿 §224.12 の表の元です。比べる相手の 1 本（2026-10-25 の門 G3 の run B の出力）は、このフォルダの外にある過去の出力です。
- `dry_run.json` — GPU を使わない確認（要求の組み立て・ファイルとヘッダー・受付の規則の検査）の、最後に回した時点（F1d・P1d・P3d の前）の記録。
- `gate_check.json` — GPU の確かめだけを回した記録。
- `runs/<項目>/result.json` — 項目ごとの記録。項目は `F0`・`F1`・`M1`（off の経路）、`P1`〜`P4`・`P1b`・`P1c`（実験の再現）、`F1d`・`P1d`・`P3d`（照合のモジュールを移したあとの回し直し）、`R`（常駐の切り替え）、`L1`〜`L5`・`L3b`・`L4b`・`L5b`（大きな画角と長い条件）、`I2V1`・`I2V2`・`REF`・`NEG`・`V16OFF`・`Q1`（ほかの入力）、`A2V`（音声の Strength 0.5）、`X1`〜`X3`・`REFc`・`REFt`（切り分け）です。
- `logs/smi_Z.csv` — P1c・L4b・L5b を回したあいだに、約 2 秒おきに取った GPU の値。見出しの行はありません。値の範囲から、時刻・GPU のメモリの使用量（MiB）・GPU の使用率（%）の 3 列と読めますが、取り方の記録は残っていません。

写したファイルは、元のファイルとバイト単位で同じです。台本は GPU を使っているプロセスの数だけを記録する作りで、起動中のアプリの一覧は記録に入っていません。写す前に、利用者名・利用者のフォルダーを含むパス・機械名・メールアドレスが含まれていないことを確かめました。

## 写さなかったもの

- 動画（`runs/<項目>/` の mp4）、並び画像（`sheets/`）、項目ごとの `metadata.json` とサーバー・ワーカーのログ、`logs/` のそのほかのログ、一時の実行環境（`_rt/`・`_dry/`）、項目 F0・M1 の補助の記録（`selftest.json`・`engine_direct.json`・`console.log`）は写していません。大きすぎるか、リポジトリに入れない慣行の物です。元のフォルダにだけあります。
- 確認の素材には、人物の実写の素材と、イラストの画像が含まれます。そのため、素材と出力の画像や動画は写していません。
