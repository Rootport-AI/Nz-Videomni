# MiniMax H3 の高速化 pi-H3 の実験（2026-11-22）の出典

pi-H3（低ステップの蒸留の差分と、動画VAE の復号器を使わずに画素を出す DWD の組み合わせ）を、製品のコードを変えずに Nz-Videomni のエンジンで動かした実験の、台本と記録の写しを置く保管庫です。台帳には無い、オーナーの直接の指示によるテーマです。結論・数値・裁定の正本は記録簿 `Docs/VERIFICATION_LOG.md` §223、仕組みと先行実装の読解は研究ノート `Docs/MINIMAX_H3_RESEARCH_NOTES.md` §18 にあり、ここには書きません。

**これは 2026-11-22 の時点の写しです。** 最初に写したあと、Retake・Inpainting・Outpainting の追試（記録簿 §223.12）を終えた時点で写し直しました。元のフォルダは git の追跡外の `outputs/h3-pih3-spike-2026-11-22/` で、正本は常にそちらです。回すときは元のフォルダの台本を使ってください（使い方は `h3_pih3_spike.py` の冒頭の説明にあります）。

## 台本（中身を変えずに写したもの）

- `h3_pih3_spike.py` — 実験の本体。製品の関数を実行時に一時的に差し替え、終わると元に戻します。GPU を使わない確認（`--dry-run`）・単発（`--single`）・連結（`--chain`）・分割（`--split`）・標準の動画VAE での復号（`--vae-decode`）に加えて、追試のための素材の切り出し（`--prepare`）・追試の項目（`--edit`）・並べ比べの画像と数値（`--post`）の使い方があります。追試の分を書き足した版を写し直しました。冒頭の説明にある計画のファイルは監督の計画ファイルで、ここには写していません。
- `pih3_adapter.py` — pi-H3 の重みのキーの照合と、LoRA 以外の差分をエンジンの本体に当てる部分。最初の写しから変わっていません。
- `pih3_dwd.py` — DWD のヘッド（隠れ状態から画素を出す部分）。作者の参照実装を読んで書いたもので、コードは写していません。最初の写しから変わっていません。

## 記録の写し

- `dry_run.json` — GPU を使わない確認の結果。追試の前に回し直した記録で、追試のための 3 項目を足した 12 項目です（写し直し）。
- `runs/<項目>/result.json` — 項目ごとの記録。項目は `P1`〜`P4`（単発）、`C3_4step`・`C3_2step`・`C3b_4step`・`C3b_2step`（連結）、`C4_4step`・`C4_2step`（分割）、追試の `R1`・`R1c`（Retake）・`I1`・`I1c`（Inpainting）・`O1`・`O1c`（Outpainting。末尾の c は pi-H3 なしの対照）です。追試の 6 項目を足しました。ほかの項目は最初の写しから変わっていません。
- `runs/C3b_4step/vae_decode.json`・`runs/C3b_2step/vae_decode.json` — 連結の潜在を標準の動画VAE で復号した対照の記録。
- `runs/C3b_4step/seam_stats.csv`・`runs/C3b_2step/seam_stats.csv` — 継ぎ目の前後（フレーム番号 100〜150）の、フレームごとの明るさと彩度の平均を、DWD で出した画素と標準の動画VAE で出した画素について並べた表。作った手順は台本 3 本には含まれていません。
- `_material/prepare.json` — 追試の素材の切り出しの記録（元の動画の場所・切り出したフレームの範囲・縮小の有無・使った ffmpeg のコマンド）。
- `runs/_compare/post.json` — 追試の並べ比べの記録。Retake の固定した頭と尾の、元の動画との一致度（PSNR）と、明るさと彩度の平均を含みます。
- `runs/_compare/R1_signalstats.csv` — Retake の、フレームごとの明るさと彩度の平均を、元の動画・R1・R1c について並べた表。

JSON の写しでは、GPU の使用状況の確認で取った起動中のアプリの一覧（`nvidia_smi_compute_apps`）を、個人情報の保護のため `(removed for privacy)` に差し替えました。そのほかは元のファイルとバイト単位で同じです。生の値は元のフォルダにあります。

## 写さなかったもの

- 動画（`output.mp4`・`output_vae.mp4`）、潜在と隠れ状態のファイル（`last_latent.safetensors`・`hidden_concat.safetensors`）、画像（並び画像・継ぎ目の比較画像・切り出したフレーム）、ログ（`*.log`）は写していません。大きすぎるか、リポジトリに入れない慣行の物です。元のフォルダにだけあります。
- 追試の元の動画は、実在の人物が写った実写の素材です。そのため、切り出した素材（`_material/` の mp4）、並べ比べの画像（`runs/_compare/` の PNG）、貼り戻しの前の画素（`runs/<項目>/raw/` の PNG）を含め、素材の画像や動画は写していません。
