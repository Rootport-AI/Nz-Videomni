**判定規則（計測前に固定）**
- 刻み＝1080p の潜在 1 コマ＝2,040 トークン。**比較は「2 回快適の上端 c」だけで行う**。溢れ側は「c の 1 段上が 2 回快適でない」ことだけを要件にする（1 回溢れ＋1 回快適の「割れ」は上端にしない）。
- 「同じ」＝int8 の c が、同一プロセスの fp8 の c と同じ段。1 段以上ずれたら「上／下」。この刻みより細かい差は検出できない。
- **逆行**（下の段が溢れ・上の段が快適）: 両点を `_r2` で取り直す。それでも残れば「非単調」と記録してその腕を止める（§11.3 の孤立した溢れの先例）。
- **単一値で表せる**: 1080p の c 以下の最大の 720p 点が 2 回快適、c の 1 段上以上の最小の 720p 点が溢れなら「表せる」。代表値は各幾何の c の最小。食い違えば「割れる」として幾何ごとに並べる。
