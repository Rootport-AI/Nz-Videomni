# Dependency snapshot of .venv-engine-h3 (MiniMax H3 engine worker interpreter).
#
# WHY: this is the reproducibility record for the known-good MiniMax H3 engine
# venv, the sibling of engine25/venv-engine-ltx25.freeze.txt (LTX 2.5) and
# engine/venv-engine.freeze.txt (LTX 2.3). There is no uv.lock. Rebuild
# reference (dependency SPEC and the reasons behind each pin):
# engine_h3/engine_h3-venv-pyproject.toml. Design: Docs/MINIMAX_H3_DESIGN.md s10.
#
# WHY A THIRD ENGINE VENV, AND WHY A DIFFERENT TORCH: the int8 ConvRot matmul of
# MiniMax H3 runs on comfy-kitchen's CUDA extension, which needs a CUDA 13 torch
# (owner rulings 11 and 16). The two LTX venvs are torch 2.9.1+cu128 and stay
# untouched; this venv is torch 2.13.0+cu130. Because the torch version differs,
# uv's hard-link sharing with .uv_cache does not reduce the footprint: this venv
# measured ~3.4 GB on disk right after the build (2026-10-17).
#
# METHOD: `uv pip freeze --python .venv-engine-h3/Scripts/python.exe` right after
# the build (uv 0.6.4), then two lines normalised by hand: torch was installed
# from a locally downloaded copy of the SAME cu130 wheel (the 1.9 GB download
# kept timing out inside uv while 54 GB of model weights were downloading in
# parallel), so its `torch @ file:///...` line is written as the index pin
# `torch==2.13.0+cu130`; sageattention is a direct wheel URL (below) written as
# `name==version`.
# Interpreter: CPython 3.12.9  (.venv-engine-h3/Scripts/python.exe)
# Captured: 2026-10-17
#
# INDEX: https://download.pytorch.org/whl/cu130 with --index-strategy
# unsafe-best-match (the cu130 index supplies torch/torchvision; everything else
# comes from PyPI). Requires NVIDIA driver R580+ and a Turing (sm_75) or newer
# GPU: CUDA 13 dropped Maxwell/Pascal/Volta.
#
# NOTE: sageattention is NOT on PyPI. Its line below is a bare pin; the only
# supported source is the direct wheel URL (libtorch stable ABI, "torch 2.10 and
# higher", cu130):
#   https://github.com/woct0rdho/SageAttention/releases/download/v2.2.0-windows.post6/sageattention-2.2.0%2Bcu130torch2.10.0andhigher.post6-cp310-abi3-win_amd64.whl
# When the installer (Ensure-EngineVenv, third call; stage 3 of the H3 alpha)
# applies this freeze, torch / torchvision / sageattention are the direct pins
# and are filtered out of the plain `-r freeze` install, exactly as the 2.5 stack
# does for its own direct pins.
#
# DELIBERATELY ABSENT: torchaudio (no cu130 Windows wheel pairs with torch 2.12+;
# the H3 path never imports it), diffsynth (its H3 model code was ported into
# engine_h3/ instead; `import diffsynth` drags in modelscope, pandas, ...),
# accelerate, gguf, ltx-core / ltx-pipelines (LTX-only).
