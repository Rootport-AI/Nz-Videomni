ここに transformer の .gguf を置くと自動認識されます（サブフォルダ可）。
fp8 の .safetensors（コミュニティが変換した LTX 2.5 用のもの。Lightricks 公式は LTX 2.5 の fp8 を配っていません）も、変換せずにここへ置けば選べます。
ComfyUI 標準の int8 の .safetensors（int8_tensorwise・asym_w4a8_int8。REDGraft のような混在も可）も同様に、変換せずに置けば選べます。
それ以外の safetensors は Nz-GGUF-Converter-LTX23 で GGUF に変換してから置いてください。
詳しくは README の「追加の transformer（GGUF／fp8 safetensors）/ LoRA を配置する」と、Docs/VERIFICATION_LOG.md §118（fp8）・§121（int8）を参照してください。
