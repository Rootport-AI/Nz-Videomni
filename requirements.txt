#     .venv\Scripts\pip install -r requirements.txt

# NOTE: The LTX inference stack (torch, ltx-core, ltx-pipelines, and the rest
# of the GPU side) is NOT listed here, and is NOT installed into this venv at
# all. It lives in SEPARATE engine venvs (./.venv-engine for LTX 2.3 and

# scripts/install_ltx.ps1, because:
#   - torch must come from the PyTorch cu128 wheel index (not PyPI), and
#   - the engine stacks pin their own torch / transformers versions (the 2.3
#     and 2.5 stacks even need different transformers major versions), so
#     they are kept out of this torch-free app venv and apart from each other.
# Attention backend: PyTorch SDPA by default; SageAttention (installed into
# the engine venvs by scripts/install_ltx.ps1) can be chosen per job.
# Neither xformers nor flash-attn is installed; there is no per-architecture
# branch and no `xformers` extra (pyproject.toml declares only the `dev` extra).
